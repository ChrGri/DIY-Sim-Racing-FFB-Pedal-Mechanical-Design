# 🧾 Order PCB

1. **Download the gerber files:** [control PCB V8](../Wiring/PcbV8/DiyFfbPedalPcbV8.zip). The power circuit is no longer on the PCB, see the [hardware brake resistor module](https://github.com/ChrGri/Diy_Hardware_BrakeResistor).
2. **Open JLCPCB:** Navigate to https://jlcpcb.com/.
3. **Upload:** Upload the gerber zip file.
4. **Settings:** Leave the standard settings (2 layers, FR-4, 1.6 mm, PCB color of your choice, see image below) and check which delivery option is the cheapest. <br>
<img src="https://github.com/user-attachments/assets/f06bf91e-a104-4cd2-86a2-3e808cb25434" width="400">
5. **Order** the PCB.
6. **Wait for the delivery:** Typically 10 days to Europe.

> [!NOTE]
> The proposed PCB is easy to source, but requires manual soldering. The awesome user [gilphilbert](https://github.com/gilphilbert) designed an SMD assembled control board with the features of the V6 PCB, which can be found [here](https://github.com/gilphilbert/DIY-Sim-Racing-FFB-Pedal-PCBs). The current status is published on the Discord channel.
